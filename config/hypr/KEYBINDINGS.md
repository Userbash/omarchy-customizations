# Keybindings

`Super` is the Windows/logo key. These are the most useful shortcuts.

| Action | Shortcut | Hint |
| --- | --- | --- |
| Open keybinding help | `Super + K` | Keybindings |
| Open the application menu | `Super + Space` | Search menu |
| Open a terminal | `Super + Enter` | Launch command |
| Open the browser | `Super + Shift + Enter` | Browser shortcut |
| Open files | `Super + Shift + F` | Files |
| Close the active window | `Super + Q` or `Super + W` | Quit/window close |
| Toggle fullscreen | `Super + F` | Fullscreen |
| Switch keyboard layout | `Alt + Shift` | |

## Windows

| Action | Shortcut |
| --- | --- |
| Focus left, right, up or down | `Super + Arrow` |
| Toggle floating mode | `Super + T` |
| Focus the next window | `Alt + Tab` |
| Move a window | `Super + Left Mouse Button` |
| Resize a window | `Super + Right Mouse Button` |

## Workspaces

| Action | Shortcut |
| --- | --- |
| Switch to workspace 1-9 | `Super + 1..9` |
| Switch to workspace 10 | `Super + 0` |
| Move a window to workspace 1-9/10 | `Super + Shift + 1..9` / `Super + Shift + 0` |
| Next/previous workspace | `Super + Tab` / `Super + Shift + Tab` |

## Quick actions

| Action | Shortcut |
| --- | --- |
| Screenshot | `Print` |
| Screen recording | `Alt + Print` |
| Clipboard | `Super + Ctrl + V` |
| Lock the computer | `Super + Ctrl + L` |
| System menu | `Super + Escape` |
| VPN client | `Super + Shift + V` |

The current Omarchy keybinding list is available with `Super + K` or:

```bash
omarchy menu keybindings --print
```
